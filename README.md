# Abubakar Idris Portfolio

Static portfolio built with semantic HTML, CSS, and vanilla JavaScript. No framework or build step is required.

## Run locally
Open `index.html` in a browser, or use VS Code Live Server for a local preview.

## Replace these placeholders before publishing
1. `images/profile.jpg` — add your professional photo.
2. `images/cbt-system.png`, `images/eventaid.png`, `images/pentavision.png`, `images/uiux-case-study.png` — add actual project screenshots. Use landscape images (roughly 720 × 440) for consistent cards.
3. `files/Abubakar-Idris-CV.pdf` — add your actual PDF CV.
4. Replace `favicon.ico` with your own favicon.
5. In `js/script.js`, replace `REPLACE_WITH_YOUR_EMAIL@example.com` with the email address you want to receive contact enquiries.
6. Replace each project link placeholder in `index.html` with a real repository, demo, website, or Figma URL. Do not publish links that do not work.
7. Verify project status labels, work dates, role descriptions, and the Triple Q Travel dates before publishing.
8. Add an actual `images/og-image.png` for social sharing. A landscape 1200 × 630 image is a useful size.

## Contact form
The current form validates fields in the browser and opens the visitor's email application with a prefilled message after you set your email in `js/script.js`. It does not send messages directly from the site. For server-side submissions, connect a backend endpoint or a form-processing provider and update the submit handler.

## Folder structure
- `index.html` — page content and SEO metadata
- `css/style.css` — layout, responsive styles, and visual design
- `js/script.js` — mobile navigation, project filters, contact-form behavior, current year
- `images/` — profile, project screenshots, and social preview image
- `files/` — downloadable CV
- `favicon.ico` — site icon

## Deploy
Upload the folder contents to a static host such as GitHub Pages, Netlify, or Cloudflare Pages. Keep paths and filename capitalization exactly as shown. Test the deployed URL and every project/social link after publishing.
